# 学习笔记 · 需求、边界、简历主线

今天没有业务代码。目标不是「看起来已经开工」，而是：**后面 9 天无论谁写代码，都有一张不能偷偷改的合同。**

你要求「做完后能自己手打整个项目」。手打的前提不是先把键盘敲热，而是先能讲清每一层为什么存在。今天练的就是这张嘴和这张纸。

---

## 1. 需求不是解决方案

错误说法：「我要做一个 Vue 页面，用 Leaflet 标点。」
正确说法：「用户要按自己的位置看到已审核店铺和距离。」

前一句是实现，后一句才是需求。实现可以换成高德、换成纯列表，需求不变。后端岗面试官问需求，是在看你会不会自己划边界。

练习：把 PRD 里任意一条故事盖住「实现」，只留「作为谁、要什么、怎样算验收」。你还能讲，这条故事才合格。

---

## 2. 用户故事怎么读

模板：

```
作为 <角色>
我想 <能力>
以便 <价值>
验收：<可打勾的现象>
```

验收必须能在 Swagger 或数据库里被证伪。

「体验要好」不是验收。
「未审核店铺 nearby 返回 0 条」是验收。
「已支付未核销的订单不能出现在评价助手」也是验收。支付只买到电子券，到店核销才算吃过。

12 条故事已经覆盖双边市场 + 交易 + 内容 + 双端 Agent + 评测。再加故事，先问它消灭了哪个新事故。消灭不了，就不加。

---

## 3. 非目标为什么比目标更重要

10 天项目死于膨胀。非目标是你给未来自己看的刹车。

面试高频问：「为什么不做套餐推荐？」
标准答：选店是约束满足，选套餐还要人数、忌口、库存、券叠加，状态空间大一个数量级，而结构化标签不够，模型会编招牌菜。所以先把店选对。

「为什么不上微服务 / ES / Kafka？」
标准答：一人团队，没有独立扩缩和全文痛点。先模块化单体。简历写扩展位，不写假装用过。

## 4. 前后端分离，你到底要懂什么

分离的意思：

```
浏览器里的 Vue  ----HTTP JSON + JWT---->  Java 主站
                                      |
                                      +----内部 HTTP----> Python Agent
```

三件事必须进你脑子：

1. **身份在请求头里**，不在前端全局变量里。前端存 token，每次带 `Authorization: Bearer ...`。后端不信前端传来的 `role` 字段。
2. **跨域是浏览器规则**。开发时 Vite 代理或 CORS 配置。这是对接必考点，不是前端玄学。
3. **写操作的真相在后端**。商家标、审核状态、库存、评价是否允许发布，全部服务端裁定。

你不需要手写 CSS。你需要能指着按钮说：它调用哪个方法、哪个路径、失败时哪个错误码、对应哪条用户故事。

AI 写前端时，你的验收话术是：「把 Network 打开，这个点击应该打到 US-0X。」

## 5. 为什么主站是 Java 21

- 交易、权限、状态机：国内后端面试的主语言。
- 21 是 LTS，新项目的默认选择。
- 你要认识：Record（不可变数据载体）、`var`、虚拟线程（高并发 IO 的一种手段）。
- 你 真正要用的仍是：Spring Web、Validation、Security、事务、MyBatis。

虚拟线程可以在八股里谈，不要在 把整个 Tomcat 换成自定义虚拟线程调度来炫技。

## 6. Agent 预告（今天只建立图像，不写代码）

你还没碰过 Agent 语言，先记住一句：

**事实在工具里，判断在模型里，签字在用户里。**

- 工具 = Java 已经算好的接口：附近店、评论、订单事实、经营数字。
- 判断 = 模型比较哪家更适合「今晚吃辣」。
- 签字 = 发评价、下单这种有后果的事，人点确认，或根本不给 Agent 权限。

PRED、CASDG 只是这两条技能的名字。会从「一次 HTTP 调用怎么变成一个工具」开始，一步一步写。今天谁先去调大模型，谁就是在跳班。

## 7. 失败模式驱动（今天的方法论）

不要先问「Agent 应该几步」。先问「它会出什么事故」。

编造店名 → 必须先检索。
空口夸店 → 必须拉评论 ID。
没吃过就评 → 必须锁订单。
自动发评 → 必须 Gate。

步骤数 = 你要拦截的事故类型。这就是「为什么不是多一步少一步」的答案。评测（）会用删除测试证明。

## 9. 今天可能被问的题（先有结构，不必长）

**如何从需求里识别非功能需求？**
看事故和约束：超卖、超时、审核可见性、幻觉、时延。它们不会出现在「用户想要一个按钮」里，但会让系统不可用。

**为什么 12 条故事适合 10 天？**
每条对应一个深度点或一个不可缺闭环。页面和组件不算故事。砍故事等于砍事故拦截，所以故事已经是下限。

**评价为什么不做匿名任意发？**
真实性、反刷、给 Agent 提供可信语料。匿名任意发会污染推荐证据和商家分析。

**前后端分离的代价？**
要处理 CORS、鉴权过期、接口版本。换来的是后端可独立验收、前端可替换。一人项目用 Swagger 兜底。

相关八股：需求 vs 非功能需求；REST 资源；JWT 原理（明天实现时再深挖）。
